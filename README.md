## Atos - Site Vitrine Institutionnel

Reproduction et adaptation du site de l'entreprise Atos, entièrement réimaginé comme une plateforme d'accueil pour attirer les futurs stagiaires de 3ème. Le design a été pensé spécifiquement pour un jeune public : une interface très visuelle, dynamique et épurée, qui va droit au but sans noyade de texte.

Contexte : Projet d'équipe réalisé en SAE 1.06 (Conception de sites web) - BUT Informatique 1ère année (IUT2 Grenoble).

## Compétences

- Front-End : HTML5 & CSS

- Dynamisation : JavaScript natif (notions de base)

- Outils : Serveur local de développement (Live Server)

## Objectifs du Projet

- Structure & Cohérence : Créer un site de 4 pages (Accueil, Engagements, Services, Rejoignez-nous) avec un design unifié.

- Maintenabilité : Centraliser le code en partageant une seule feuille de style et un seul script pour tout le site.

## Techniques et Savoir-faire Appris

- HTML : Structuration propre des pages avec des balises modernes ("header", "nav", "main", "footer") pour un code lisible et bien découpé.

- Design CSS Centralisé : Gestion dans un unique fichier style.css (Hero image, mise en page, typographies) pour éviter la duplication.

- Micro-interactions JavaScript : Ajout pour améliorer l'expérience utilisateur :

  - Système d'accordéon (bulles dépliables/repliables au clic dans "Nos Services").

## Structure du projet

